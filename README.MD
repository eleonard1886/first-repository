# Python Basic Practice

This repository contains practice exercises and examples for the Python Basic course from Platzi.

## Project Overview

The project is designed to help reinforce fundamental Python concepts, such as:

- Variables and data types
- Control flow (if, for, while)
- Functions and modules
- Data structures (lists, tuples, dictionaries, sets)
- File I/O
- Basic object-oriented programming

## Repository Structure

- `README.MD` - Project overview and instructions
- `exercises/` - Practice scripts and course examples
- `notes/` - Personal notes and code snippets
- `resources/` - Reference materials and links

## Getting Started

1. Install Python 3.8 or newer.
2. Clone the repository:

   ```bash
   git clone <repository-url>
   ```

3. Navigate to the project folder:

   ```bash
   cd platzy_courses/python_basic
   ```

## Running the Examples

From the project root, run any Python script using:

   ```bash
   python3 exercises/example_script.py
   ```

Replace `example_script.py` with the file you want to test.

## Contribution

Add new practice files inside the `exercises/` folder and keep notes updated in `notes/`.
